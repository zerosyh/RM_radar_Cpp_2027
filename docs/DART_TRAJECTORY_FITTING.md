# 反导弹道拟合与预测（终版文档 v4：全程 2s 短飞）

> 定稿：2026-08-23（v4 修订：飞行总时长 ~2s，重做拟合窗口与时间预算）
> 适用：RM2026/2027 哨兵雷达站反飞镖（反导）功能——飞镖弹道拟合、命中预测、拦截点解算。
> v4 相对 v3 的关键修改：**① 拟合窗由滑动短窗（1.2s）改为全程积累式拟合**（2s 飞行 ≈20 帧，滑动窗浪费 60% 观测，应全部利用）；**② 加入"发射点-目标点"两点约束**（发射站与模块位置均已知，2s 短飞对早期预测是极大先验）；**③ 时序预算按 2s 重排**（0.3~0.8s 出首个预测，0.8s 后进入拦截窗口）。

---

## 0. 前提：飞镖的真实飞行原理

**RM 飞镖 = 无螺旋桨、无喷气、无动力的视觉制导滑翔弹**（队伍实物确认 + 官方规范佐证）：

| 事实来源 | 内容 | 对建模的含义 |
|---|---|---|
| 官方制作规范（2025 V1.2.0，2026 赛季沿用） | "飞镖依靠自带的**视觉系统**定位飞镖检测模块，通过螺旋桨（**最多**允许使用 1 个）、舵面、喷气等方式控制飞行方向……**飞镖推重比需小于 1**" | 制导存在（视觉）；无推力（推重比<1 = 无动力滑翔特征） |
| 官方制作规范 / 规则手册 | 发射架提供**初始动力**（储能弹射；禁压缩空气直推）；发射架 **Pitch 25°~45°**；飞镖 ≤0.24kg、≤250×150×150mm | 发射点/仰角范围强约束；小惯量、舵效有限 |
| 规则 5.6.5 | 目标可选"固定/随机固定/随机移动/末端移动"；模块 ±0.28m 移动、600ms 内完成 | 制导机动带宽有限：目标突然换位仍可脱靶 |
| 规则 4.2.2 / 制作规范 | 命中判定 = 头部触发装置（TPU 壳 20g，红外发射）撞击小装甲模块 + 红外同时 | 打坏头部触发装置 = 命中判定失效（拦截软肋） |
| **队伍实测（v4 新增）** | **飞镖总飞行时间 ≈ 2s**（全程约 20 帧 @10Hz） | 一切时间预算、拟合窗大小、拦截窗口都要按 2s 设计 |

**弹道形态** = 无动力滑翔 + 视觉制导闭环的平滑弯曲下滑曲线：
- 无动力 → 能量单调递减，速度持续衰减；
- 制导（比例导引类）→ 弹道持续弯向目标；舵效有限 → jerk 有界、带宽受限；
- 末段视线角速率 → 0 → 近直线俯冲（末段约 0.3~0.5s）。

## 1. 弹道模型：三阶幂级数（恒 jerk）

```
p(t) = c0 + c1·Δt + c2·Δt² + c3·Δt³        Δt = t - t_now
c0 = 当前位置    c1 = 当前速度    c2 = 加速度/2    c3 = jerk/6
```

2s 全程的段划分（与 3 阶模型的关系）：

| 段 | 时间 | 特征 | 三阶模型表现 |
|---|---|---|---|
| 初段 | 0~0.3s | 弹射离架，舵效未建立，弹道≈发射方向直线 | J→0 直线段 |
| 中段 | 0.3~1.6s | 制导主段：弹道弯向目标，转弯率缓变 | **J≠0 有界**（横向加速度近似线性变化） |
| 末段 | 1.6~2.0s | 视线收敛，近直线俯冲 | J→0，退化为直线 |

**为什么三阶就够**：舵效有限 = 制导带宽受限 = 弹道是"加速度连续、jerk 有界"的平滑曲线 → 三阶泰勒展开是它的精确局部描述；三段全部落在同一个三阶多项式的参数区间内，**不需要模型切换、不需要 IMM**（CV/CA 不是制导镖的真实模式，放进去只会稀释概率）。

## 2. 拟合算法（v4：全程积累式拟合）

### Step 0｜前提（一次性标定）

- 点云转**地图系**（TF：livox→map，须先完成雷达配准标定）；
- 精确时间基 = 点云 header 时间戳（不用帧号）；
- 飞镖走廊区（对方半场 z∈[1.4,3.5]）离线 PCD kd-tree 背景减除（阈值 0.20m）；
- 标定**发射点 P_launch**（飞镖站滑台，场地坐标，规则/地图已知）与**模块位置**（自检阶段引导灯亮时点云/相机标定）。

### Step 1｜每帧观测提取

```
单帧点云（地图系）→ 走廊过滤（z∈[1.4,3.5]）→ DBSCAN(eps=0.2m, min≥5)
  → 每簇: 剔除 >2σ 离群点 → 质心 p_k
  → σ_k = sqrt(tr(簇内点协方差)/N)      近 0.03m / 远 0.08m
```

- 不做点级 3 帧累积（时间混叠）；单帧 <5 点 → 该帧弃用（有其它帧）；
- 多簇多轨道分别处理（30s 窗口内 4 连发）。

### Step 2｜帧间关联

```
p_pred = p_now + c1·ΔT（ΔT≈0.1s）
‖p_k - p_pred‖ < max(0.5m, |c1|·ΔT·0.5)  → 关联
未关联 → 新轨道；连续 5 帧无观测 → 删轨（命中/脱靶/遮挡）
```

### Step 3｜拟合：全程积累式（不滑动、不留窗）

**v4 核心变更**：2s 飞行 = 20 帧观测，全部都是有效信息——**从首帧到当前帧的所有观测进拟合**，随弹道增长（0 帧 → 20 帧），参数随帧数增稳。不做滑动窗（窗口只会丢数据），不做时间衰减权重（2s 内弹道无"过期"概念，旧帧与当前帧同等可信，因为是同一连续弹道）。

**阶数随帧数自适应（启动策略）**：

```
第 1 帧            : 无拟合，纯检测
第 2~3 帧          : 速度估计（相邻帧差分 v = ΔP/ΔT）→ 可用直线粗外推
第 4~5 帧（0.4s）  : 2 阶拟合（3 参数/轴，正好刚过可解阈值）
第 6+ 帧（0.6s+）  : 3 阶拟合（4 参数/轴，20 帧全程稳定）
残差 RMS >0.1m 且 ≥15 帧: 升 4 阶（可选验证）
```

**数学**（每轴独立，x/y/z 共用设计矩阵）：

```
时间基准: u = (t_k - t_launch) / T_norm      T_norm = 2.0s（全程归一化，防 Vandermonde 病态）
M[k] = [1, u_k, u_k², u_k³]
w_k = 1/σ_k²                                （等权精度加权，无时间衰减）
c = (MᵀWM)⁻¹ · MᵀW·p                        （4×4 正规方程）

实现: 累积加权矩 S[m]=Σw·u^m (m=0..6)、T[m]=Σw·u^m·p (m=0..3)
      每帧: 20×10 乘加 + 解一次 4×4 —— 微秒级
```

**抗离群（一次 Huber 迭代）**：解出 c → 残差 |e_k|>0.15m 的帧权重乘 0.15/|e_k| → 重解一次。

### Step 4｜两点约束（v4 新增，早期预测的兜底）

已知先验：**发射点 P_launch**（飞镖站固定）、**目标 T_target**（模块位置，±0.28m 移动带）、**发射仰角 25~45°**。用正则化把先验拉进拟合（早期帧数少、参数不稳时尤其重要）：

```
min  Σ w_k‖p_k - M·c‖²  + λ1·‖P(0) - P_launch‖²  + λ2·‖P(τ_hit) - T_target‖²  + λ3·‖V(0) - v0_prior‖²

v0_prior: 由仰角 25~45° 与能量估计的初速范围（15~25 m/s），给区间约束而非点约束
λ 取值: 帧数<6 时 λ 大（先验主导，防拟合发散）；帧数≥10 后 λ→0（数据主导）
```

- 效果：0.3~0.5s 时只有 4~6 帧，纯拟合外推 1.5s 的误差可达 0.5~1m；加两点约束后早期外推命中点被"拉向"模块 → **早期阶段直接就能给出可用的命中时刻窗**（制导镖本来就是飞向模块的，这不是假设是制导结果）；
- 只在早期/残差异常时启用，数据充分后自动退出（λ 随帧数衰减）。

### Step 5｜输出

```
位置/速度/加速度/jerk = c0/c1/c2/c3（换算回秒单位后）
短外推 (τ≤1.0s):  P(t_now+τ) = c0 + c1·τ + c2·τ² + c3·τ³（u 归一化坐标下外推）
协方差:           C = (MᵀWM)⁻¹；σ(τ) = [1,τ,τ²,τ³]·C·[…]ᵀ
命中时刻:         z(t)=z_target 求根（归一化区间数值解，闭式二次解 + 一次 Newton 修正）
```

## 3. 时序预算（按 2s 全程重排）

```
t=0       飞镖离架（滑台点云消失/弹射信号）
t=0.1~0.3 雷达首次捕获（走廊检测）              → 首检延迟目标 <0.3s
t=0.3~0.5 4~6 帧 + 两点约束 → 首个预测          → 首个 /dart_target（命中窗,精度粗）
t=0.6~0.8 8~12 帧，3 阶全程拟合收敛 → 精预测    → 首个 /dart_intercept 候选
t=0.8~1.6 制导主段：段判定 LOCKED，持续更新
t=1.6~2.0 末段 TERMINAL（近直线）→ 拦截窗口     → 哨兵开火（弹丸飞行 0.1~0.35s，命中 1.7~2.0s）
t=2.0     命中（或被拦截/脱靶）
```

- **哨兵拦截预算**：末段 0.4s 窗口 + 弹丸航时 0.1~0.35s（哨兵与模块距离 3~15m、弹速 25~30 m/s）→ **最后 0.5~0.6s 决定成败**；弹道预测必须在 t=0.8s 前收敛到 σ<0.3m，否则哨兵只能靠末段直线目视，机会很小；
- 因此 **t=0.3~0.8s 的预测精度是反导成败的关键**（这就是为什么两点约束+全程积累拟合比滑动窗重要）。

## 4. 预测策略（分段）

### 4.1 短外推（τ≤1.0s，幂级数）

```
σ(0.5s) ≈ 0.05~0.1m；σ(1.0s) ≈ 0.15~0.4m
外推 >1.0s：幂级数发散风险（u⁴ 项），超过即无意义
```

### 4.2 长时域（>1.0s，制导锚定，不做单点外推）

```
命中点 = 模块当前位置 (x_m, y_m, z_target)（前哨站固定 / 基地 ±0.28m y 移动带）
命中窗 = [τ_hit - σ_τ, τ_hit + σ_τ]
        σ_τ ≈ σ_v/|v_z| + a_max·τ_hit²/(2|v_z|)

段判定:
  TRACKING  = 早期，残差正常，两点约束生效 → 命中窗初值
  LOCKED    = 短窗外推命中点与模块偏差 <0.5m 且持续 → 反制点=模块位置+命中窗
  TERMINAL  = 末段（|c3|·6·τ³ < 0.05m 或残差 <0.05m、速度指向目标）→ 供拦截
  ABNORMAL  = 外推命中点与模块偏差持续 >0.5m → 制导失效/失控，报真实坠点+告警
```

## 5. 反制点（哨兵拦截）

- **拦截窗口 = TERMINAL 段**（1.6~2.0s，近直线，J→0）；
- **交会解算**（3 次迭代）：

```
g(t*) = ‖P_dart(t*) - P_sentry - v_b·û·(t* - t_fire)‖      t_f = t* - ‖d‖/v_b
迭代: 弹丸沉降修正 d_z ← d_z - ½·g·t_f²；一维搜索最小化 g(t*)
输出: (x*, y*, z*, t*, t_fire)
```

- **瞄准点选软肋**：舵面/翼面（打坏 → 制导失效必然脱靶）或头部红外触发装置（打坏 → 命中判定失效）；飞镖轴向≈速度方向，目标点 = 质心 ± 轴向半长·速度单位向量；
- `g(t*) < 0.05m` 才发拦截点，否则只发预警。

## 6. 参数与标定清单

| 参数 | 含义 | 初值 | 标定方法 |
|---|---|---|---|
| flight_time | 飞镖总飞行 | **2s**（队伍实测） | 滑台消失→模块命中帧 |
| v0 | 弹射初速 | 15~25 m/s | 轨迹首段一阶导 + 仰角 25~45° 先验 |
| a_max | 制导横向加速度上限 | 1~4 m/s² | max(2·c2) 观测 |
| J | jerk 尺度 | 0.5~3 m/s³ | 6·c3 观测 |
| σ_k | 质心噪声 | 0.03(近)/0.08(远) | 簇协方差 |
| T_norm | 归一化时基 | 2.0s | = flight_time |
| 残差阈值 | Huber/异常 | 0.15 m | 实测 |
| 两点约束 λ | 正则权重 | 帧数<6: 强；≥10: 0 | 残差最小化调优 |
| z_target | 模块装甲面高 | 标定 | 自检阶段引导灯亮标定 |
| v_b | 哨兵弹速 | 25~30 m/s | 实测 |

**标定前提：先做点云配准**，否则轨迹数据无意义。

## 7. 准确性说明

| 误差来源 | 大小 | 控制 |
|---|---|---|
| 观测质心抖动 | 0.03~0.08m | 剔除 2σ + 精度加权 |
| 全程拟合（≥10 帧） | <0.05m | 全帧积累（20 帧 + 等权统计效率最高） |
| 早期 4~6 帧 | 0.1~0.3m | **两点约束正则化兜底** |
| 短外推 0.5s / 1.0s | ≈0.05~0.1m / 0.15~0.4m | 协方差传播 |
| >1.0s 外推 | 不可用 | 制导锚定（命中窗+段判定） |
| 制导机动 | 含在 σ(τ) 增长 | a_max 定界 |
| 目标移动 ±0.28m | 命中点带 | 已含不确定度 |
